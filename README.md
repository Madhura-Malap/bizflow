## 📌 Project Overview

BizFlow is a modern web-based Business Management System designed to streamline and digitize the daily operations of an organization. Developed using the Flask framework, the application provides a centralized platform for managing business activities such as client records, projects, employees, complaints, invoices, and business analytics.

The system eliminates the need for manual record-keeping by offering an intuitive dashboard, real-time business insights, and efficient data management. It is designed with scalability, usability, and maintainability in mind, making it suitable for small and medium-sized businesses.

This project was developed as part of an Industrial Internship at **Pratyush Advertising**, with the objective of improving operational efficiency through digital transformation.

## ⚙️ Installation

Follow these steps to set up the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Madhura-Malap/bizflow.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd bizflow
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the Application

```bash
python app.py
```
