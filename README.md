# BizFlow – Business Management System

A comprehensive web-based Business Management Portal developed during an Industrial Internship at **Pratyush Advertising Pvt. Ltd**. The system digitizes and streamlines the company's daily operations by providing a centralized platform for managing clients, projects, employees, complaints, invoices, and business analytics.

---

## 📌 Project Overview

Pratyush Advertising Management System (PAMS) is designed to replace manual record-keeping with an efficient digital solution. It enables business administrators to organize operations, monitor ongoing projects, generate invoices, and gain valuable business insights through an interactive dashboard.

The application focuses on improving productivity, reducing manual effort, and providing a better decision-making experience using real-time business data.

## 🚀 Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project directory

```bash
cd Pratyush-Advertising-Management-System
```

3. Create a virtual environment

```bash
python -m venv venv
```

4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run the application

```bash
python app.py
```
